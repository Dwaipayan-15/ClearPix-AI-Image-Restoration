# ClearPix — AI Image Restoration

**Deep Learning | CNN Autoencoder | TensorFlow/Keras | Python**

ClearPix is a deep learning project focused on restoring noisy images using a Convolutional Neural Network (CNN)-based autoencoder. The goal is to develop a model that learns to reconstruct cleaner images from noisy inputs and present the results through an interactive web application.

## Project Overview

Images can become noisy or degraded during acquisition, transmission, or storage. ClearPix aims to reduce this noise using deep learning rather than relying exclusively on traditional image-processing filters.

The model will be trained using clean images and their artificially corrupted counterparts. Once trained, it will attempt to reconstruct a cleaner image while preserving important visual details.

**Project status:** 🚧 In Progress

## Objectives

- Develop a CNN-based autoencoder for image denoising.
- Train and evaluate the model using an appropriate image dataset.
- Compare noisy input images with restored outputs.
- Evaluate restoration quality using quantitative metrics.
- Build an interactive web interface for testing the trained model.

## Proposed Methodology

1. **Dataset preparation:** Collect suitable images and preprocess them into a consistent format.
2. **Noise generation:** Add controlled noise to clean training images to create noisy-clean image pairs.
3. **Model development:** Design an encoder-decoder CNN autoencoder using TensorFlow/Keras.
4. **Model training:** Train the network to reconstruct clean images from noisy inputs.
5. **Evaluation:** Measure reconstruction quality using Peak Signal-to-Noise Ratio (PSNR) and Structural Similarity Index (SSIM), where appropriate.
6. **Web application:** Develop an interface that allows users to upload images and compare the input with the restored output.

## Proposed Model Architecture

The project will use a CNN-based autoencoder consisting of:

- **Encoder:** Extracts image features and learns compact representations.
- **Bottleneck:** Captures compressed representations of important image information.
- **Decoder:** Reconstructs the image from the learned representation.
- **Output layer:** Produces the restored image.

The model will be trained by comparing its output against the corresponding clean target image using an appropriate reconstruction loss function.

## Evaluation Metrics

| Metric | Purpose |
|---|---|
| PSNR | Measures reconstruction quality relative to pixel-level error |
| SSIM | Measures structural similarity between images |
| Reconstruction Loss | Measures the difference between predicted and target images during training |

Model performance and final metric values will be reported after implementation and evaluation.
